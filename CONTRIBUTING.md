# Como contribuir

Este projeto é um caderno de estudos, mas melhorias são bem-vindas.

Sugestões:

- corrigir erros técnicos;
- melhorar a clareza das explicações;
- adicionar referências abertas e confiáveis;
- propor novos exercícios;
- revisar prompts.

Ao adicionar conteúdo técnico, informe a fonte utilizada sempre que possível.
